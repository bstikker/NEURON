# Input data

This directory contains the input files required to run the pipeline.

* `test_data/` contains a small anonymized example dataset for testing and validating the pipeline installation.
* Users should place their own sequencing data in a separate subdirectory within `input/` and update the configuration file (`config/samples.yaml`) accordingly.

The example dataset is intended solely to verify that the pipeline executes successfully and does not represent a complete clinical sequencing run.
